## 本地维护与公开内容

- Git 只跟踪 `docs/`、发布脚本及本说明；学习画像、个人约定、原始聊天引用和本机复核记录留在本地。
- `docs/` 中的 Markdown 可直接在 GitHub 阅读；同目录 HTML 用于网页阅读。
- 在其他设备可以编辑 `docs/` 下的 Markdown，然后重新生成 HTML。原机器如需从私人学习库重新导出，应先同步并合并其他设备的改动，避免覆盖。
- 修改知识卡片的掌握重点时，同时更新学习地图中的对应卡片；默认构建只重新渲染 Markdown 文章，不自动推断或改写卡片内容。

```powershell
python -m pip install -r requirements-publish.txt
# 根据仓库已有的公开 Markdown 重新生成网页
python scripts/build_public.py
# 仅在有原始学习库的机器上，审查后从本地重新导出公开版
python scripts/build_public.py --from-local
```

发布前运行 `python scripts/check_public.py`。脚本检查链接与部分常见敏感内容，不能替代人工审阅。

## 开启网页访问

仓库创建并上传后，进入 **Settings → Pages → Deploy from a branch**，选择 **master /docs**，保存。GitHub 完成部署后会显示实际网页地址。未核实部署完成前，不将预期地址当作已上线。

结构图使用固定版本的 Mermaid 浏览器模块；该资源加载失败时仍保留正文解释与图的文本。互动地图和案例切换无需外部 API。

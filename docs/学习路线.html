完成起步三篇后，可以沿此表继续扩展。这里按项目主题组织，不要求一次读完。

你已经提出的关键设计要求

  • 接入新游戏要快，同时尽量不影响已有游戏。
  • 共同能力可以复用，具体游戏保持独立。
  • 多个 agent 要有合理分工，不能只是不断增加数量。
  • 做完要交代怎么解决、验证了什么。

可以把这些要求转成可检查的问题：新游戏关闭时旧游戏是否正常？切换时是否还会执行旧动作？失败时聊天和语音是否继续可用？工具是否只执行一次？

自测

试着不用项目术语解释：为什么“把一个新游戏放进独立文件夹”还不足以证明它与旧游戏解耦？答案应涉及接口依赖、共享资源、任务失效和回归验证。
